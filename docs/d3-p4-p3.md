# D3, P4, P3 — Financement, fonds affectés, états financiers bouclés

Code : `src/lib/tresorerie.ts` (D3), `src/lib/fonds.ts` (P4), `src/lib/etats.ts` (P3), `src/lib/moteur.ts` (enchaînement). Montants en milliers de la monnaie de pilotage.

## D3 — Financement et trésorerie
- **Comptes** multidevises convertis en monnaie de base (solde d'ouverture consolidé).
- **Emprunts** : existants (annuités constantes dès l'année 0) et nouveaux tirages issus de D2 (remboursés dès l'année suivante) ; intérêts sur le capital d'ouverture. `simulerEmprunt` : annuité, coût total, tableau d'amortissement, différé optionnel.
- **Plan mensuel de 12 à 18 mois** : encaissements selon un **calendrier de facturation** (12 % par mois depuis la rentrée, somme 100), paie, fournisseurs, CAPEX, service de la dette, ressources (tirages, fonds affectés). Point bas, couverture en mois de charges, alerte sous le seuil ou si le solde est négatif.
- Le plan annuel de trésorerie (15 ans) est le tableau des flux de P3.

## P4 — Fundraising et fonds affectés
- Promesses de dons : montant × probabilité, calendrier d'encaissement, affectation (libre, bourses, projet).
- Dons libres : produits de l'exercice. Fonds affectés : passif jusqu'à leur emploi ; l'emploi pour le CAPEX est plafonné aux fonds reçus, l'écart est un **manque à financer autrement** (alerte).

## P3 — États financiers bouclés
- **Compte de résultat par nature** : scolarité nette, inscriptions, annexes, subventions, dons libres, produits financiers ; personnel (B3), fonctionnement (C1), PFC, amortissements (D2), intérêts et frais de découvert (D3). Vue analytique par catégorie et centre de coût.
- **Bilan** : immobilisations nettes (D2), créances familles, trésorerie ; fonds propres, fonds affectés (P4), emprunts (D3), dettes fournisseurs, concours bancaires.
- **Flux de trésorerie** : exploitation (résultat + dotations − variation du BFR), investissement, financement (tirages, capital remboursé, fonds affectés reçus).
- **Contrôles bloquants** : bilan équilibré ; variation des fonds propres = résultat (hors apports de fonds affectés employés) ; flux = variation de trésorerie ; trésorerie de clôture = trésorerie du bilan. Un scénario non bouclé est signalé (alerte « états non bouclés »).
- **KPI** : marge nette, masse salariale sur recettes, jours de charges couverts, endettement sur fonds propres, point bas de trésorerie.

## Moteur de scénario (`executerScenario`)
A1 sur la demande → besoin en salles (D1) → projets d'extension proposés → effectifs plafonnés par les salles → structure par année (B1) → recettes et PFC (A2/A3) → couverture et créations de postes (B2) → masse salariale (B3) → charges (C1) → CAPEX (D2) → dette (D3) → fonds (P4) → états bouclés (P3) → plan mensuel (D3). Testé de bout en bout, y compris avec l'IB et après un changement de monnaie de pilotage.

## Limites actuelles
- L'emploi de fonds affectés rejoint les fonds propres sans reprise progressive en produits ; les bourses internes financées par fonds ne passent pas encore par le compte de résultat.
- Les créations de postes ne réduisent pas les HSA de l'année calculée : elles s'ajoutent à la masse salariale à partir de leur année d'effet.
- Comparaison réalisé / budget / prévision et versions de scénarios (P2) : à faire.
- Les données du moteur sont fictives dans les tests : calibrage sur LFKL à faire quand les postes, contrats, espaces et paramètres financiers seront fournis.
