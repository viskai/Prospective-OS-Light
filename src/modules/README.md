# Modules

Un dossier par brique du cahier des charges (§5 à §7) : `a1-effectifs`, `a2-tarifs`, `a3-subventions`,
`b1-structure`, `b2-emplois`, `b3-rh` (isolé), `c1-sg`, `d1-espaces`, `d2-capex`, `d3-tresorerie`,
`p1-drivers`, `p2-scenarios`, `p3-etats`, `p4-fundraising`, `dashboard`.

Règle : un module publie des drivers dans le registre (P1) ; il n'écrit jamais directement dans les états financiers.
